## 使用原则

1. 所有AI、写手、审核员、总策划处理本书前，**先读 `SOURCE_MANIFEST.md`**。
2. 资料优先级：**S0已发布正文 > S1作者最新明确确认 > S2旧设定/旧大纲 > S3动态大纲/模型方案**。
3. GitHub当前正式资料优先于旧聊天、旧项目来源、旧压缩包和历史副本。
4. 已发布正文属于不可修改正史；如果作者后续提供某章正式正文，该正文事实仍高于仓库整理表。
5. 若资料冲突，必须标记冲突，不得擅自圆设定。
6. 战力一致性属于最高执行优先级之一：先战力，后剧情；升级必须留下永久成长痕迹。

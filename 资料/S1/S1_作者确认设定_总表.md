# 第一编 世界尺度与政治关系

## 1. 世界尺度【S1-01】

正式世界尺度为：

**小界 → 中界 → 大界 → 界域 → 混沌宇宙 → 无尽混沌**

硬定义：

- **大界 = 一座宇宙。**
- “大界”不是“大世界”的泛称，而是真正宇宙级尺度。
- 大约上百万座大界，可以组成一座界域。
- 一座混沌宇宙之中拥有无数界域。
- 相对于整座混沌宇宙，一座界域只类似浩瀚海洋中的一朵浪花。

当前林易所在政治/领土关系大致为：

**九州小界 → 岁月神国 → 北苍神朝**

边界规则：

- 这是**政治、领土关系**，不是宇宙尺度的同义换算。
- 不得擅自把“北苍神朝”直接等同于一整座大界、界域或混沌宇宙。
- S0已经出现“世界群”术语，但本次S1未锁定“世界群”在六级正式世界尺度中的位置，未来不得自行映射。

# 第二编 天赋等级与林易当前高阶天赋

## 2. 天赋等级体系【S1-02】

原始六级：

**纯白 → 赤红 → 明黄 → 苍青 → 玄紫 → 曜金**

正式向上扩展：

**曜金 → 十都 → 九曜 → 八极 → 七元 → 六司 → 五老 → 四御 → 三清 → 二祖 → 一尊**

| 等级 | 大致定位 | 稀有/时代尺度 | 大致潜力定位 |
|---|---|---|---|
| 曜金 | 小界历史级 | 数万年可能出现一个 | 神体较容易；一般能成不死已相当不错 |
| 十都 | 中界当代级 | “当代”约万年一代 | 洞天境潜力 |
| 九曜 | 中界历史级 | 可能十亿年才出现；中界寿命约千亿年级 | 世界境潜力 |
| 八极 | 大界当代级 | 大界=宇宙；数亿年一出 | 真神潜力 |
| 七元 | 大界历史级 | 无数亿年级别罕见 | 神帝潜力 |
| 六司 | 界域当代级 | 到界域尺度，千亿年、上万亿年仍可能算“当代” | 封号神帝/神尊潜力 |
| 五老 | 界域历史级 | 未锁具体年限 | 天尊潜力 |
| 四御 | 混沌宇宙当代级 | 未锁具体年限 | 仍属天尊级潜力，但远高于普通五老，属于顶尖天尊种子 |
| 三清 | 混沌宇宙历史级 | 未锁具体年限 | 道主/道果境潜力 |
| 二祖 | 道主中的至强潜力 | — | 向掌控一方混沌宇宙发展；核心概念“己心代表天心” |
| 一尊 | 永恒超脱 | — | 最终超脱混沌宇宙乃至无尽混沌体系 |

**特别规则：**

- 天赋等级代表**稀有度、潜力、生命层次评价**。
- 不等于必然达到对应境界。
- 绝对不能直接写成固定战斗倍率。
- 不得用“十都=固定×10”“九曜=固定×100”之类方式机械换算战斗力。

## 3. 林易已确认的重要高阶天赋【S1-03】

当前重要高阶天赋：

- **八极：意志主宰**
- **九曜：向死而生、水之道体**
- **十都：万法通玄、战神×2**

重复战神规则：

- 两份战神能产生一定叠加增幅。
- **没有质变。**
- 三个十都级天赋也未必能融合成半步九曜。
- 不得为方便剧情随意降低高级天赋融合难度。

# 第三编 正式修炼境界与高层称号

## 4. 已锁主境界【S1-04】

已发布正文锁死的主境界顺序：

**神体境 → 不死境 → 洞天境 → 世界境 → 真神境**

硬规则：

- 顺序不可修改。
- “天神”目前不能自行设定成正式修炼境界。
- 北苍神帝明确属于超过真神的高层存在。
- 神帝属于真神之后的重要层级。
- 真神以后到神帝之间的完整正式阶梯**尚未全部锁死**。

- **没有封伯。以后绝对禁止加入封伯。**
- “封王”“神君具体位阶”等若未被作者继续锁定，也不得自行补成完整阶梯。

## 5. 真神以后已锁定称号【S1-05】

### 封侯

- 封侯是真神阶段已经确认存在的重要称号。
- **封侯真神才能真正开辟神国。**
- 岁月真神属于：**封侯真神**。
- 岁月神国就是岁月真神的神国。

### 神君

- 神君数量并不少。
- 可能十几位、几十位，具体数量尚未锁定。

### 三祖

- **三祖不是境界。**
- 三祖是神君群体之中最强大的三位神君。
- 三祖实力已经接近神帝，但与真正神帝仍有巨大差距。
- 面对神帝，三祖大致能够做到**保命**，不是平等抗衡。
- 三祖特别强的重要原因之一：掌握了**无上神通**。

### 神帝

- 神帝是真神之后的真正大层次之一。
- 北苍神帝属于这一层次。
- 七元级天赋大致对应神帝潜力。

### 封号神帝 / 神尊

- 封号神帝也叫：**神尊**。
- 六司级天赋对应封号神帝/神尊潜力。
- **不得把六司对应成神君。**

# 第四编 战力体系

## 6. 神体境战力硬标准【S1-06】

神体境内部裸基础：

- 神体一重 → 神体二重：约**10倍**。
- 神体二重 → 神体三重：再约**10倍**。

神体品质：

**下品 → 中品 → 上品 → 极品**

- 每提升一个品质，基础力量约提升**10倍**。
- 因而中品神体一重的纯基础，大致可媲美下品神体二重；上品、极品依次类推。

未锁边界：

- “极品神体一重是否仅裸基础就超过不死境一重”**尚未最终锁死**。
- 禁止模型将其写成硬倍率结论，只能结合S0已发布战斗事实校准。

神体三重 → 不死境一重：

- 属于重大生命层次变化。
- 作者当前设想存在**约百倍级别的巨大基础跨越**。
- 但最终战力必须综合判断，不得只用这一个数字裁决。

## 7. 神兵、神通、武学增幅规则【S1-07】

禁止：

**基础 × 神兵 × 神通 × 武学 × 天赋**全部机械相乘。

总原则：

- **基础越高，同样增幅产生的绝对战力越大。**
- 战力必须综合境界、根基、道、神通、武学、神兵、技艺、天赋、克制、状态。

### 神兵

- S0中人阶上品神兵曾让当时林易综合实力产生约十倍级提升。
- 高品质、完全适配、能够发挥威能的神兵，可以产生一个巨大档位增幅。
- 高境界神兵落到低境界人物手中，不代表低境界人物能够发挥全部威能。

### 神通

神通强度高度依赖：

- 当前基础
- 修炼篇章
- 修炼到第几转
- 适配程度

《黑魔战天身》是典型案例：同一神通不同境界、不同转数效果差距极大。

### 武学 / 战斗技艺

- 武学/战斗技艺是核心战力维度。
- 战神天赋主要提升的就是这一部分。
- 因而不能把“战神单独×10”后再把“武学×10”，造成重复计算。

## 8. 洞天境根基体系【S1-08｜2026-09-03清理旧口径】

突破路线：

**不死境 → 洞天境**

突破洞天后，原本以神体为主要载体的根基发生质变，核心逐渐变成：

**洞天**

硬规则：

- 洞天不是普通穴窍。
- **洞天境的核心根基只看洞天数量，不再另设“洞天质量”这一独立维度。**
- 能开辟几口洞天，本身就是突破前神体根基、大道感悟、逆天材料与整体积累质量的最终体现；前置条件越强，才越有资格开辟更多洞天。
- 进入洞天境后，不得继续把“神体品质”无限当成主要乘数；神体、感悟、材料等价值已经在最终能够开辟的洞天数量上得到集中体现。
- 原则上多开辟一口洞天，可形成接近一个**10倍级别**的巨大根基差距，但不得机械化到所有最终实战。

### 九洞天

- 九洞天属于极其逆天的最高层次根基之一。
- 当前恢复出的重要条件之一：**至少需要一条至高真意达到第四重以上（至少第四重）。**
- 还需要大量极其逆天的材料和其他根基条件。
- 完整条件尚未锁定，禁止模型自行补满。

开天天才校准：

- 有一位极端妖孽天才掌握**开天至高真意第一重**。
- 他当前根基大致最多足以冲击**八洞天级别**。
- 想达到九洞天仍明显不够。

# 第五编 道体系

## 9. 道必须区分“品质”与“参悟境界”【S1-09】

两个维度绝对不能混淆：

- **A：道本身是什么品质。**
- **B：修行者把这条道参悟到什么层次。**

当前大体分类：

### 基础之道

金、木、水、火、土、风、雷、光等。

### 更高级大道

例如五行、阴阳、刀、剑、星辰、天象等。

> 具体完整名单以后继续校准，本次不锁满。

### 至高大道

时间、空间、因果、命运、混沌、开天、生命、毁灭、真一等概念中，最终正式九条体系另做表。

> 当前禁止模型根据这些候选概念强行填满最终九条至高大道名单。

### 参悟层次

**近期已锁：**当前林易继续沿用“真意”这一主称；S0旧文中的“道之意境”原样保留。

**远期暂行工作口径（待最终确认）：**  
**真意1—9重 → 道之域境1—9重（简称道域） → 完整掌握一条道**

边界：

- “真意1—9重”与当前林易既有修炼线可直接承接。
- “道域1—9重”以及它与“完整掌握一条道”的精确衔接，当前只作为远期策划工作口径，**不得当成已经在S0正式公布的完整体系**。
- 近期正文不需要提前科普“道域”。
- 已发布正文曾使用“道之意境”等称呼，不修改。
- 237章以后当前修炼线主称“真意”，不得倒改已发布正文。

## 10. 不同品质之道不能只看重数【S1-10】

核心原则：

- 低品质大道九重，不一定比高品质大道一重强。
- 当前用于战力/悟道校准的近似锚点为：**至高真意第一重 ≈ 普通大道的道域第一重 ≈ 完整掌握一条较低层次的基础之道**。
- 这是跨品质的**近似校准**，不是所有大道、所有战斗场景都能机械套用的数学等式。

因此：

- 掌握开天至高真意第一重的超级天才，哪怕自身修为很低，单论大道感悟也可以不弱于很多真正真神。
- 真正大界中的顶级不死境天才，道之感悟完全可能比很多普通世界境更高。
- 审核战力时禁止用“真意第几重”单一数字跨品质硬比较。

# 第七编 开天天才与混元塔

## 14. 混元塔完整设定【S1-14】

混元塔按境界分别存在：

- **神体境混元塔：1—100层**
- **不死境混元塔：1—100层**
- **洞天境混元塔：1—100层**
- **世界境混元塔：1—100层**

用途：衡量对应境界下的**综合战力和天才层次**。

已发布标准继续有效：

| 神体境塔层数 | 定位 |
|---:|---|
| 第1层 | 已经极难；大量普通中品神体的神体境三重甚至过不了 |
| 第10层 | 有望洞天 |
| 第30层 | 有望世界境 |
| 第50层 | 有望真神 |
| 第70层以上 | 神帝之资 |
| 第100层 | 真正难以想象的神体境极限 |

规则：

- 混元塔不是每层机械增加十倍。
- 可大致理解为每十层左右存在一次重要层级变化。
- 30、50、70、100等关键节点尤其重要。

林易S0战绩：

1. 第一次：神体境一重，**止步30层**（通过29，败于30）。
2. 第二次：神体境三重，**通过36层，止步37层**。

长期约束：

- 作者原设计本不准备让林易这么早到37层，但S0已经发布，不能改。
- 未来必须主动压制混元塔层数膨胀。
- 水火融合成功后也绝不能随意直跳50、60层。
- 混元塔必须作为长期战力标尺，而不是一次性爽点数字。

## 15. 混元塔真正来历【S1-15｜后台秘密】

- 混元塔由：**混元天尊**亲自创造。
- “混元塔”之名来自混元天尊。

知情范围：

- 【作者已知】是。
- 【林易当前已知】**否。**
- 【当前普通公众是否完整知晓】未锁定，不得擅自写成人人知道。

正确揭露时机：

- 未来混元天尊正式出现、准备收徒或相关事件发生时。
- 可通过旁人震惊与林易询问“混元天尊是谁？”反向揭露“你一直闯的混元塔，就是混元天尊创造的”。

## 17. 混元天尊创造的诸天世界【S1-17｜远期】

混元天尊曾创造大量不同世界，可成为林易未来重要修炼/历练副本。

风格：

- 接近真正的诸天无限流。
- 不是进去打一座塔两章就出来。
- 每个世界可拥有完整文明、历史、王朝、门派、体系、本土人物和核心矛盾。

# 第九编 天尊与高层神通/传承

## 20. 天尊层次【S1-20】

- 天尊远在神帝、神尊之上。

## 21. 无上神通【S1-21】

未来混元天尊门下：

- 无上神通仍然珍贵。
- 但在天尊亲传培养体系中，它是正常的顶级培养资源。

- “到了天尊那里无上神通就是垃圾。”
- “林易随便全学。”

正确口径：地图升级后，资源层级重新定位，但顶级资源依然需要适配与选择。

# 第十编 混沌宇宙、九条至高大道与道主

## 23. 混沌宇宙与九条至高大道【S1-23】

整个混沌宇宙最初天然存在的至高大道只有：

1. **时间**
2. **空间**

其余七条至高大道：

- 不是宇宙天生存在。
- 由后世七位伟大道主**亲手创造**。

因此一共：**九条至高大道**。

构成：

- 2条天然大道：时间、空间。
- 7条后天大道：分别由七位历史道主创造。

历史道主：

- 历史上共有七位“创造大道的道主”。
- 目前仍存世的道主只有：**五位**。
- 因而有：**两位历史道主已经陨落。**

未锁事项：

- 七条后天至高大道的最终名称。
- 每位历史道主分别对应哪一条。

**禁止模型自行补齐。**

## 24. 道主的本质【S1-24】

后期世界观核心：

**天尊是在学道。**  
**道主是在创造道。**

机制：

- 一个道主出现之前，混沌宇宙里可能根本不存在某条大道。
- 道主创造这条大道后，整座混沌宇宙从此才拥有它。
- 后世无数生命学习、参悟、修炼这条大道，本质上都在“学习这个道主”。

核心概念：

**“你所修之道，本就是我。”**

大道成长：

- 后世修炼该大道的生灵越多，理解越多、完善越多、衍生越多，这条大道本身会越来越强。
- 作为大道源头的道主也会因此受益。

因此：

- 天尊与道主不是简单“战力高十倍”的关系。
- 两者在生命层次、修炼逻辑上都发生巨大变化。

魔祖：

- 自身实力比青玄道主略强一些。
- 青玄一方并非原则上反对有人突破更高层次。
- 真正忌惮魔祖的重要原因是魔祖性情、道路过于邪恶。
- 一旦魔祖真正掌控整座混沌宇宙，后果可能无法接受。

## 26. 道主、掌控、合道【S1-26】

五大道主最终都在追求：

**与自己所在整座混沌宇宙融合，最终掌控一方混沌宇宙。**

- 掌控境
- 合道境

- 成功完全掌握一方混沌宇宙后，会成为无尽混沌中极其强大的存在。

## 8. 后续正文风格

作者希望整体吸收“我吃西红柿式商业玄幻”的高层特征，但**不是机械模仿具体句式**：
- 行文直接；
- 信息清晰；
- 战斗逻辑容易看懂；
- 战力层级明确；
- 少空泛文艺和抽象感悟；
- 修炼成果尽快实际验货；
- 爽点来自“以前做不到、现在做得到”的实力反馈；
- 战斗不要水大量无效来回；
- 强敌为什么强，靠真实配置说明；
- 主角为什么敢打，必须有现实依据和底牌，不无脑莽。

尤其248类战斗：先把双方强弱逻辑写清楚，再写新成果如何改变战局；不能为了所谓战斗精彩强行压低林易。

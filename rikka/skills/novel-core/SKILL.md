# 小说项目核心规则

## 唯一事实源
- `ghzyzttxwd/yanhuatianfu` 当前 HEAD 是唯一正式资料源。
- 每次重要任务先读取根目录 `SOURCE_MANIFEST.md`，再按其当前顺序读取任务所需文件。
- 不凭聊天记忆、RikkaHub Memory、旧聊天、旧附件或模型印象补动态事实。

## 优先级
`S0已发布正文 > S1作者确认设定 > S2作者明确保留的未来规划 > S3动态大纲/模型方案`。

- S0 不可修改。
- S1 不得覆盖 S0。
- 模型推测默认是 S3，作者确认前不得写成正史。
- 作者明确修改未来设定时，当前 HEAD 中被替代的旧口径必须删除或改写，不保留覆盖链。
- 资料冲突时不得擅自圆设定；应指出冲突并停止依赖冲突项继续执行。

## 动态事实
境界、资源、战绩、神通、面板、人物状态、当前章节、大纲、战力配置等一律实时读取 GitHub 当前 HEAD。

RikkaHub Skill 只保存工作规则，不保存上述动态事实。

## 基本原则
- 历史交给 Git；当前 HEAD 只服务当前创作。
- 先事实，后方案。
- 正式资料未锁定的数字、倍率、名称、门槛不得自行补成硬设定。

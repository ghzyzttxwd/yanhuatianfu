# 独立审核员执行规则

审核结论分：通过 / 修改后通过 / 不通过。

A级：S0冲突、严重S1冲突、战力崩坏、境界错误、历史战绩被遗忘、核心状态错误、资源凭空出现、关键秘密提前泄露、重要因果无法成立。A级存在时不得进入下一章。

B级：大纲偏移、局部时间/资源连续性、轻微OOC、伏笔处理不当、节奏明显失衡。

C级：对白、句式、描写、钩子等优化项，不为挑错而挑错。

每次必须专项检查：
- 战力：双方九维、历史锚点、升级反馈、是否临时削弱/拔高、混元塔反校。
- 大纲：本章功能是否完成、是否提前消费后续、是否产生需要滚动改纲的新事实。
- 连续性：时间、地点、人物、伤势、资源、面板、伏笔、知情范围。
- 商业结构：资源→面板→天赋→成长→验货→新资源是否仍在运转。

不要替写手辩护；资料本身冲突则标记“资料库冲突，请总策划/作者裁定”，不要擅自补洞。

# 一、世界尺度

## 1. 正式宇宙尺度【S1】

**小界 → 中界 → 大界 → 界域 → 混沌宇宙 → 无尽混沌**

| 尺度 | 已锁定义 |
|---|---|
| 小界 | 正式最低一级世界尺度之一；九州为小界 |
| 中界 | 高于小界；S0已出现墨仓中界等 |
| 大界 | **一座宇宙** |
| 界域 | 大约由上百万座大界组成 |
| 混沌宇宙 | 拥有无数界域；一座界域相对其只如海洋一朵浪花 |
| 无尽混沌 | 混沌宇宙之上的最终大背景尺度；细节以后再锁 |

**未锁映射：**S0“世界群”未被本次S1纳入正式六级尺度，禁止自行等同任何一级。

## 2. 当前政治/领土关系【S0+S1】

**九州小界 → 岁月神国 → 北苍神朝**

- S0：九州所在区域归属于北苍神帝麾下的岁月神国；岁月神国由岁月真神开辟。
- S1：这条链是政治/领土关系，不等于宇宙尺度链。
- 北苍神朝究竟覆盖几座大界/界域：**未锁。**

# 三、正式修炼境界与已锁高层称号

## 1. S0锁死主境界

**神体境 → 不死境 → 洞天境 → 世界境 → 真神境**

不可修改。

## 2. 真神之后目前只锁部分节点，不得强行补全整条阶梯

### 封侯真神

- 属于真神阶段的重要称号。
- 封侯真神才能真正开辟神国。
- 岁月真神 = 封侯真神。

### 神君

- 数量不少，可能十几/几十位，具体未锁。

### 三祖

- **不是境界。**
- 是神君中最强三位。
- 接近神帝，但只能在神帝面前争取保命，不是平等抗衡。
- 掌握无上神通是其超常战力的重要原因。

### 神帝

- 真神之后的重要大层次之一。
- 北苍神帝属于此层次。
- 七元大致对应神帝潜力。

### 封号神帝 / 神尊

- 两者为同一层级称谓。
- 六司大致对应神尊潜力。

### 天尊

- 远在神帝、神尊之上。
- 内部分**三个境**。
- 三境名称未锁，禁止命名。
- **完整掌握至少一条至高大道，是突破天尊的硬门槛之一。任何真正的天尊都必定已经完整掌握至少一条至高大道。**成为天尊后仍可继续参悟其他至高大道，并通过多道融合推进天尊内部更高境。

### 道主 / 道果层面

- 三清大致对应道主/道果潜力。
- 道主本质不是简单更强的天尊，而是“创造道”的生命层次。

### 掌控/合道

- 五大道主最终追求与整座混沌宇宙融合并掌控。
- “掌控境”“合道境”的正式关系尚未锁定。
- 不得擅自排成两个连续境界。

### 一尊终极方向

- 最终不是仅掌控混沌宇宙，而是**超脱无尽混沌**。
- 终极境界名未锁。

### 明确禁项

- **没有封伯。**
- “天神”目前不是正式修炼境界。
- 不得自行创造封王、神君细分等完整阶梯。

# 四、道体系

## 1. 两个维度必须分开

### 道的品质

- 基础之道：金、木、水、火、土、风、雷、光等。
- 更高级大道：五行、阴阳、刀、剑、星辰、天象等（名单未锁满）。
- 至高大道：最终九条，部分名称/来源已锁，完整表未锁满。

### 参悟境界

**近期已锁：**当前修炼线主称“真意”，S0旧称“道之意境”保留历史文本。

**远期暂行工作口径（待最终确认）：**  
**真意1—9重 → 道域1—9重 → 完整掌握一条道**

其中“道域1—9重”及其与完整掌握之间的精确衔接，当前不视为S0已经正式公布的硬体系；近期正文不提前科普。

## 2. 跨品质战力原则

- 低品质道九重不一定强过高品质道一重。
- 近似校准：**至高真意第一重 ≈ 普通大道道域第一重 ≈ 完整掌握一条较低层次基础之道**；用于量级判断，不是机械数学等式。
- 因此低修为顶级天才可在大道感悟上超过高修为普通强者。

# 六、道主的修炼本质

**天尊是在学道，道主是在创造道。**

- 道主创造某条大道之前，混沌宇宙可能根本没有这条大道。
- 创造后，后世修炼者实际上都在学习这位道主。
- 后世参悟、完善、衍生越多，大道本身越强，源头道主也会受益。

核心概念：

**“你所修之道，本就是我。”**

这意味着天尊→道主不是简单数值提升，而是生命层次和修炼逻辑跃迁。

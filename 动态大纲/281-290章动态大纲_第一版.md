# 281—290章动态大纲｜第一版

> 资料等级：S3动态大纲。作者未明确确认前不得提升为S1。
> 承接：280章林易在陨星海完成第一轮资源争夺，大神通不死篇第二转已在安全环境中修成并完成实战验货，水火融合真意已在脱战后消化推进至第六重；假身份开始在陨星海外围流传，并已有猎杀者暗中跟踪。
> 本段核心：从“主动争资源”切换成“被猎杀→反猎杀”；重点磨真正的星空生死经验、新刀道技艺、不死二后期积累和财富循环。不得把林易重新写成遇见普通洞天就苦战。
> 战力护栏：林易此时已经能正面击杀二洞天·洞天二重级普通老牌冒险者；因此本段威胁主要来自【多人协作、情报差、伏击、追踪、环境和退路封锁】，不是把单个普通敌人临时拔高。

## 本段敌对势力

- S3暂称：【黑隼猎队】。名称未锁，可后改。
- 定位：长期混迹陨星海、专门盯落单冒险者和大额战利品的职业猎杀队，不是大势力核心人物。
- 核心配置：
  - 首领：二洞天·洞天二重，成熟猎杀/追踪技艺，地阶极品神兵，无神通；
  - 副手：二洞天·洞天一重，擅长正面牵制；
  - 三名成员：一洞天层次，分别负责侦查、封路、远程骚扰/支援；
  - 全队长期合作，真正威胁来自配合与围杀经验，不额外发明夸张阵法倍率。
- 这支队伍整体联手可以给林易制造真实危险，但任何单人都不得无理由超过其既定配置。

## 第281章｜尾巴

- 林易离开交易点后，很快确认自己被人盯上。
- 对方并不是破解了元河九重传承塔第一层隐匿宝物，而是通过交易点的公开动向、目击路线和“陌生不死二重突然处理大批高阶材料”的异常行为进行人工跟踪。
- 林易不急着甩掉他们，反而故意维持当前路线，借此判断人数与层次。
- 他逐渐确认后方至少不止一人，而且前方也有人提前绕路，明显是在布围杀口袋。
- 林易没有通知元星、也不动用公开亲传身份；既然出来历练，这种局面本就是历练的一部分。
- 章末：林易主动偏离安全航线，进入一片破碎星辰密集区。跟踪者以为他想逃，全部跟了进去。

## 第282章｜五个人

- 黑隼猎队第一次正式现身，五人形成前后夹击。
- 首领不废话装逼，直接判断：林易有高额战利品、身份不明、没有公开背景，是合适猎物。
- 双方第一次群战。
- 战力表现：
  - 林易单对任何一人都占优势；
  - 但五人多年配合，首领正面扛、副手牵制、其余人封路和骚扰，迫使林易无法像单挑罗岳一样快速完成击杀；
  - 不得写成五个普通洞天把林易正面压得毫无还手之力。
- 林易短暂交锋后不恋战，利用破碎星辰地形主动脱出围杀圈。
- 黑隼猎队确认林易远比预估强，但仍认为五人合围有机会，而且林易身上的收获足够大，决定继续追。
- 林易脱离视线后第一次反向锁定他们：既然对方不准备停手，他也不准备只逃。

## 第283章｜第一个

- 林易利用隐匿宝物和复杂星体遮蔽制造假路线，让黑隼猎队不得不拆开一定距离搜索。
- 负责侦查的一洞天成员率先落单。
- 林易突然反杀。
- 这不是Boss战：以林易当前实力，对普通一洞天成员必须迅速解决，数次有效攻击内斩杀。
- 林易取走对方通讯器物/地图，通过其中有限信息确认猎队大致人员组成与常用汇合方式。
- 不做“破解全部情报”的万能情报外挂，只获得当前战局合理能获得的信息。
- 黑隼猎队很快发现成员失联，首次意识到：他们追的不是一只会逃的肥羊，而是一个会主动反猎杀的强者。

## 第284章｜第二个

- 黑隼猎队开始收缩队形，不再继续五人分散。
- 林易利用自己已经掌握的汇合规律，抢在其彻底抱团前截住副手。
- 副手：二洞天·洞天一重。
- 这一战必须体现林易永久成长：副手的层次已经不够资格承担苦战，林易以大神通第二转＋水火六重＋新刀技稳定压制并快速斩杀。
- 副手死后，剩余猎队只剩首领＋两名一洞天成员。
- 首领第一次产生退意，开始准备撤走，不再因为“兄弟死了”降智死磕。
- 但林易已经从对方先前的行动确认：这些人不仅要杀他，还会出售猎物情报。为了避免自己的假身份战斗情报被持续转卖，他决定把这次追杀彻底处理干净。

## 第285章｜现在轮到我追了

- 黑隼猎队身份关系彻底反转：三人开始撤，林易在后面追。
- 首领利用熟悉陨星海的优势选择一条危险但复杂的撤退路线，希望借自然环境甩掉林易。
- 林易不盲目直追，而是利用之前缴获的路线信息和星图提前截击。
- 双方发生第二次多人大战。
- 首领二洞天·洞天二重，两个一洞天成员从两侧辅助，整体仍能制造真实压力。
- 林易开始明显感受到自己新刀道技艺目前的一个不足：单次爆发和正面对杀已经够强，但在同时处理多个方向、连续衔接攻击时还不够圆融。
- 他击伤一名成员，却没有强行在三人联手下追求必杀，主动再次拉开距离。
- 本章功能不是“打不过”，而是让林易从多人实战里找到新技艺下一步明确问题。

## 第286章｜乱星涡带

- 黑隼猎队三人逃入陨星海更深处一片自然危险区，S3暂称【乱星涡带】。
- 林易暂时停止追击，先恢复伤势、消化连续数战经验。
- 他找到一处相对安全的破碎星体内部，花数日专门推演元星所授新刀道技艺。
- 重点不是凭空领悟新绝招，而是解决上一章暴露出的“力量彼此割裂、连续变招不够圆融”的问题，让神力、水火、大神通和刀势衔接得更紧。
- 八极通用悟性再次兑现长期价值。
- 新刀道技艺进入一个更成熟层次，但本段暂不锁正式“第几重/第几转”名称，等功法结构最终确认后再对应。
- 同时林易发现乱星涡带深处存在高价值星髓/矿材活动痕迹；这里既是猎场，也可能继续带来资源，不让追杀线脱离商业循环。

## 第287章｜杀回去

- 林易完成数日整理后重新追踪黑隼猎队。
- 此时不是境界突破，只是技艺更成熟、状态恢复完整。
- 借乱星涡带复杂环境，他先后截住剩余两名一洞天成员。
- 两场小战快速处理，不逐个水成完整Boss章；以明显优势斩杀。
- 首领终于彻底成为孤身一人。
- 林易从其中一人的空间戒指里发现：黑隼猎队多年猎杀积累远比普通冒险者丰厚，而且他们身上还保留着不少其他死者的未处理资源。
- 首领见所有队员接连死亡，不再想任何交易，开始全力逃离陨星海这片区域。
- 林易拦在前方。

## 第288章｜谁才是猎物

- 林易与黑隼猎队首领进行最终一对一。
- 首领九维：二洞天·洞天二重、成熟猎杀技艺、地阶极品神兵、无神通、全盛转为连续追逃后的轻度消耗，无特殊克制。
- 战力审核：这一配置和此前罗岳属于相近大标尺，但林易已经在罗岳战后拥有稳定水火六重，又经过连续反猎杀把新刀技磨得更成熟，所以本战必须比罗岳战明显轻松。
- 首领依靠隐匿、变向、逃命经验拖延，却无法在正面对杀中翻盘。
- 林易不需要再次临场突破任何东西，凭现有体系稳步压制并最终斩杀。
- 这一战的爽点是纵向反馈：同档敌人在林易继续成长后，已经从阶段Boss变成“有手段、但结局没有悬念”的对手。
- 黑隼猎队彻底覆灭。

## 第289章｜猎人的家底

- 林易清点整支猎队的多年积累。
- 收获来源明确分账：
  - 五名猎杀者自身的灵石/丹药/材料；
  - 长期猎杀其他冒险者尚未来得及处理的战利品；
  - 乱星涡带中顺手获得的一批高价值矿材；
  - 一份通往陨星海更深区域的老旧星图/资源情报，可作为下一阶段地图入口，但不保证情报百分百正确。
- 林易把适合变现的部分换成灵石，再次给面板进行一次明显的大额充能。
- 仍不擅自锁具体百分比，也不强行安排新的天赋衍化；是否够下一次衍化等正文账本真正结算时确定。
- 经过这段时间持续实战、资源供给和元星此前给予的不死境培养资源，林易的修为也被推到【不死境二重巅峰附近】。
- 他没有继续带着不稳定状态往深处闯，而是主动寻找真正安全的地方，准备完成境界积累。

## 第290章｜不死三重

- 林易在远离主要航线的一处荒废星体/封闭碎片内部停留，确认周边安全后正式闭关整理。
- 先恢复伤势、稳固水火六重和新刀技，再用已有不死境修炼资源补齐最后修为积累。
- 【突破不死境三重】安排在完整脱战、安全环境中完成，绝不边和敌人厮杀边升级。
- 突破重点写基础和生命层次再次提升，但不夸成跨大境界天地异象。
- 突破完成后，林易重新校准自身战力：比281章进入反猎杀时又有显著永久提升，但此处不直接宣布已经超过三山老祖，更不能自动判定可过元河九重传承塔第二层。
- 更重要的是，按元河神宫既定阶段培养规则：达到不死境三重后，大神通【不死篇第三转】的修炼阶段正式具备开启条件。
- 章末钩子：林易结束闭关，准备先处理第三转与更深层历练，再决定何时回去挑战元河九重传承塔第二层。

# 281—290阶段验收

- 修为：不死境二重 → 【不死境三重】；
- 大神通：第二转保持完成，第三转在章末具备开启条件，但本段不直接修成；
- 水火：稳定第六重，不提前冲七重；
- 刀道技艺：通过多人围杀与反猎杀明显成熟，具体层数暂不锁；
- 面板：猎队财富＋资源再次形成大额充能进度，但不无账本强行衍化；
- 战斗经验：从正面单挑扩展到追踪、反追踪、拆分围杀、多人环境和追逃战；
- 战力反馈：普通一洞天已完全退出Boss位；二洞天洞天一也能快速解决；二洞天洞天二单挑从阶段硬仗逐步变成明确优势；
- 长期目标仍保持：先继续历练，把不死三＋大神通第三转＋刀道技艺等真正推到接近三山老祖，再挑战元河九重传承塔第二层；通过第二层后借奖励完成水火第七重，最后回头正面碾压三山老祖。

# 291以后暂定方向

下一批优先处理：
1. 林易以假身份继续进入陨星海更深区；
2. 找安全节点完成大神通不死篇第三转，而非临战突破；
3. 引入比黑隼猎队更高质量的冒险者/天才竞争，不再重复普通猎杀团；
4. 逐步把实际综合战力推到三山老祖附近；
5. 条件成熟后回元河九重传承塔挑战第二层。

具体章数和第二层挑战时间暂不锁，等281—290实际正文落点后滚动调整。

# 《资质差？可我能无限衍化天赋啊！》续写总资料库

本仓库是本书续写项目的唯一正式资料源。

## 唯一入口

任何 AI、写手、审核员、总策划开始工作前，**必须先读 `SOURCE_MANIFEST.md`**。

不要从 README 判断当前章节、当前战力、当前资源或当前大纲；README 只说明仓库用途，不维护动态状态。

## 资料优先级

**S0 已发布正文 > S1 作者确认设定 > S2 作者保留规划 > S3 动态大纲/模型方案。**

具体执行规则、当前有效资料、读取顺序和当前工作目标，以 `SOURCE_MANIFEST.md` 为准。

## 目录

- `正文/`：当前已归档的实际正文。
- `资料/S0/`：已发布正史硬事实、历史状态锚点、人物关系、伏笔线程。
- `资料/S1/`：作者确认的新设定与修订。
- `资料/战力/`：战力体系、历史战绩锚点、当前阶段校准。
- `动态大纲/`：当前滚动规划，属于 S3。
- `工作规则/`：总策划、写手、审核员执行规则。
- `工作稿/`：当前续写工作状态。
- `scripts/`：仓库一致性自动检查。

## 核心治理原则

**历史交给 Git，当前 HEAD 只保留当前创作仍需要的有效资料。**

被替代、废弃或仅用于迁移的文件不得继续留在当前 HEAD 中污染检索。

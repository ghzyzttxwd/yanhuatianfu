# 《资质差？可我能无限衍化天赋啊！》续写总资料库

本仓库是本书续写项目的正式资料库。

## 使用原则

1. 所有AI、写手、审核员、总策划在处理本书前，**先读 `SOURCE_MANIFEST.md`**。
2. 资料优先级：**S0已发布正文 > S1作者最新明确确认 > S2旧设定/旧大纲 > S3动态大纲/模型方案**。
3. GitHub当前正式文件优先于旧聊天、旧项目来源、旧压缩包和历史副本。
4. 已发布正文属于不可修改正史；后续资料不得反向覆盖S0。
5. 若资料冲突，必须标记冲突，不得擅自圆设定。
6. 战力一致性属于最高执行优先级之一：先战力，后剧情；升级必须留下永久成长痕迹。

## 目录

- `SOURCE_MANIFEST.md`：唯一入口，说明当前正式源、读取顺序与版本状态。
- `正文/`：S0已发布正文1—236章，按章节区间拆分保存。
- `资料/S0/`：已发布正史整理表、人物势力、当前状态、伏笔线程。
- `资料/S1/`：作者确认设定总表、世界尺度与最新作者增量。
- `资料/战力/`：战力体系、混元塔与重要战绩校准。
- `动态大纲/`：近期S3动态大纲；正文一旦实际发布，以正文为准。
- `工作规则/`：项目工作流、正文写手与审核标准、商业节奏规则。
- `工作稿/`：尚未升级为S0的正文/审核材料，只作工作记录。
